01 / What it does

Everything a SQLite file needs, in one window

Open several databases at once, browse and edit rows, inspect schema, run raw SQL, and keep the file honest with backups and integrity checks.

Browse & edit

Tables, rows, and tabs

  • Multiple databases open at once, each in its own tab
  • Sorting, pagination, and SQL-expression filters
  • Insert, edit, duplicate, and safely delete rows
  • Current table, page, and filter are preserved per tab
SQL console

Run real queries

  • Multi-statement scripts, not just single SELECTs
  • Templates for SELECT, INSERT, UPDATE, DELETE, and schema
  • Per-database query history with timing and results
  • One-click load and rerun of past queries
Schema design

Structure, not just data

  • Create, rename, empty, and drop tables with confirmation
  • Composite foreign keys with ON UPDATE / ON DELETE actions
  • CHECK constraints, STRICT tables, WITHOUT ROWID tables
  • Unique, expression, ordered, and partial indexes
  • Create, edit, and drop views and triggers
Import & export

Move data in and out

  • Import CSV rows into an existing table
  • Export a table or view as CSV or JSON
  • Export the full database as SQL
  • Convert .sql / .csv into .db, .sqlite, .sqlite3, .db3
Maintenance

Keep the file healthy

  • Consistent backups and integrity checks
  • PRAGMA inspector plus WAL checkpoint, optimize, vacuum
  • Detects external .db changes and refreshes safely
  • Attach and detach databases, edit connection PRAGMAs
Look & feel

Twelve installed themes

  • phpMyAdmin-style theme selection
  • Compact and comfortable layout density
  • Native file dialogs and a normal resizable window
  • Recent databases in the native File menu

04 / Or run from source

Three commands, no server

Install Node.js 22 or newer

SQLiteScope runs on Electron, which bundles the SQLite engine — nothing else to install.

Clone and install dependencies

git clone https://github.com/connect2sazad/sqlitescope.git cd sqlitescope npm install

Start the app

npm start

On Windows, double-click Start-SQLiteScope.vbs instead — it stays terminal-free and logs setup to logs/sqlitescope-startup.log. On Linux, run ./start-sqlitescope.sh.

Want an installer instead of running from source? See Build installers in the docs.

05 / Trust

Local by default, honest about limits

◆

No telemetry, no cloud

No analytics, advertising, cloud sync, or automatic upload. The renderer has no direct filesystem or Node.js access — database work runs through an isolated preload API.

◆

Confirmations on destructive actions

Dropping a table, deleting rows, or running schema migrations always asks first. Back up important databases before large changes.

◆

SQLite files only

SQLiteScope is not a MySQL/PostgreSQL client. Encrypted databases need the relevant encryption extension and aren't supported by this build.

◆

Commits happen immediately

SQLite commits your SQL right away unless it explicitly opens a transaction — plan bulk edits accordingly.
