# Privacy

SQLiteScope is local-first software.

- Database files are opened directly from locations selected by the user.
- Database contents are not uploaded, synchronized, sold, or shared by SQLiteScope.
- SQLiteScope contains no analytics, telemetry, advertising SDK, or user account system.
- Recent file paths and the selected theme are stored locally in Electron's application-data directory.
- Export and backup files are written only to destinations selected by the user.
- External network access is not required for normal database use. The Documentation menu opens the public project website in the system browser.

Users remain responsible for access controls, backups, and the confidentiality of database and exported files on their device.
